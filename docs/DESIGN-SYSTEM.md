# Design system: "Jemuran di hari cerah"

The brand world comes straight from the logo: a straw bucket hat, a smiling
sun, soft clouds and four-point sparkles. The site extends it into **a sunny
afternoon with laundry drying on the line**. The hero's clothesline (real
products pegged to a rope) is the one bold, memorable element; everything else
stays calm.

## Principles

1. **Sun + sky.** Warm marigold/sunflower are balanced by a cool sky blue, so
   the palette never collapses into a generic cream-and-orange.
2. **Sticker depth.** Instead of blurry shadows, primary surfaces use the logo's
   hard ink offset shadow (`sticker`, `shadow-offset`). Use it sparingly:
   primary buttons, step cards, the CTA band.
3. **Soft geometry.** Big radii (1–3rem), pill buttons, scalloped section edges.
4. **Motion with purpose.** The clothesline sways gently; elsewhere motion only
   answers user actions. Everything respects `prefers-reduced-motion`.
5. **Plain, warm copy** in Bahasa Indonesia.

semantic (`--primary`, `--muted`…, consumed by shadcn/ui) → Tailwind utilities.

on `marigold` (≈7:1). WhatsApp green carries white text with an ink outline.

## Typography

| Role    | Face          | Notes                                         |
| ------- | ------------- | --------------------------------------------- |
| Display | Young Serif   | Soft retro serif echoing the logo's "Malik"   |
| Body/UI | Nunito (var.) | Rounded, friendly, very legible at small size |

Scale (≈1.25): `text-display` (fluid, up to 68px) → `text-title` (fluid, up to
44px) → `text-2xl/xl/lg` → body 17px / 1.6. Headings are balanced
(`text-balance`), paragraphs `text-pretty`, lines ≤ ~65ch. No all-caps labels.

## Shape, depth, spacing

- Radius scale: `--radius: 1rem`; cards 1.75–2.5rem; buttons/chips `rounded-full`.
- Shadows: `shadow-offset-sm` (rest) → `shadow-offset` (hover) → none (pressed).
- Layout: `container-page` (max 76rem, 16/24/32px gutters); sections `py-12–24`.

## Icons: `src/components/brand/icons.tsx`

A custom set on a 24px grid with 1.9 stroke and round caps/joins. Brand glyphs
(Hanger, Cotton, Stitch, Sparkle, Sun) sit beside utility icons. Icons are
`aria-hidden` unless given a `title`. Add new ones with `createIcon()`.

## Illustration

- **React illustrations** (`illustrations.tsx`): SunMascot, Cloud, Sparkle,
  StrawHat, EmptyBasket (empty search), LostSock (404), ScallopEdge.
- **Product art** is generated by `scripts/art/garments.ts`: 12 garment
  silhouettes × 6 fabric patterns, flat fill + ink offset shadow, in four
  views (`-1` front, `-2` on hanger, `-3` fabric detail, `-hang` with pegs for
  the clothesline) plus a 1200² JPG for social/structured data. Replace with
  real photos any time (see [CONTENT.md](CONTENT.md)).

## Components

shadcn/ui (Base UI) primitives restyled through tokens: `Button` variants
`default` (sticker), `whatsapp`, `ink`, `outline`, `secondary`, `ghost`,
`link`; Sheet (mobile nav, filters), Dialog (size guide), Accordion (FAQ,
product details), NativeSelect (sort).
